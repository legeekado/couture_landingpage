# Kalmy — Landing page

Site vitrine du SaaS Kalmy (couturiers au Sénégal).

## Lancer en local

```bash
cd landingpage
npm install
npm run dev
```

Ouvre [http://localhost:3001](http://localhost:3001).

Les boutons « Se connecter » et « Créer un atelier » pointent vers le backoffice (`NEXT_PUBLIC_BACKOFFICE_URL`, défaut `http://localhost:3000`).
